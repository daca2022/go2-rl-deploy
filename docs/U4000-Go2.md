# A2/P0 U4000 en MuJoCo y en el Go2

El paquete incluye el [actor TorchScript](../model/a2-p0-u4000.ts) y su [manifiesto](../model/manifest-u4000.json). U4000 completó las seis pruebas de pendiente sin caerse. Aprobó tres con el criterio completo de trote. U2400 completó cuatro y aprobó dos. En el último corte de desarrollo, U4000 aprobó 15/20 en plano y el lateral quedó en 0/5. [Datos emparejados](Resultados-Pendiente-A2.csv) · [Video en +5°](Demo-A2-U2400-U4000-Pendiente.mp4).

## Actualizar y probar en MuJoCo

Desde el repositorio en la PC Ubuntu 22.04, actualiza la copia e instala el panel si es la primera vez. El [README](../README.md) incluye el comando para clonar.

```bash
git pull --ff-only
if [ ! -x .venv-a2/bin/python ]; then bash install-panel.sh; fi
mkdir -p pruebas
.venv-a2/bin/python replay.py forward --policy-update 4000 --view \
  --csv "pruebas/u4000-sim-$(date +%Y%m%d-%H%M%S).csv"
```

También puedes abrir `bash abrir-panel.sh` y elegir **4000** en **Checkpoint GRU**. El panel usa el [puente MuJoCo por DDS](Adaptador-A2-Go2.md#1-mujoco-por-dds) para la prueba de simulación.

En MuJoCo por DDS, U4000 completó los 20 s para cada una de las cuatro consignas sin caídas. El error lateral fue de 0,111 m/s. [Resultados de la prueba DDS](Prueba-A2-U4000-DDS.json).

## Ethernet y prueba pasiva

Con la Ethernet de desarrollo configurada y el Go2 quieto, identifica la interfaz con `ip -br addr`. Sustituye `enp3s0` por tu interfaz. El cliente usa el [SDK2 Python oficial](https://github.com/unitreerobotics/unitree_sdk2_python/tree/814556d15970dd2ecf1c9984e845ca02ab07e206) directamente por DDS.

```bash
IFACE=enp3s0
.venv-a2/bin/python a2_robot.py shadow --policy-update 4000 \
  --iface "$IFACE" --seconds 10 --command forward \
  --csv "pruebas/u4000-shadow-$(date +%Y%m%d-%H%M%S).csv"
```

`shadow` recibe telemetría y guarda los objetivos calculados en CSV. No publica comandos a los motores. En el panel, usa **Go2 · GRU en sombra** con el checkpoint **4000**.

## Pulso físico en banco

El [procedimiento de banco](Adaptador-A2-Go2.md#3-go2-físico-primer-pulso-a2-en-banco) requiere un perfil verificado de tu Go2, el controlador Sport desactivado, la unidad sostenida con las patas libres y el paro físico disponible. Con esas comprobaciones, selecciona **4000** en el panel o pasa `--policy-update 4000` al comando de banco documentado. El pulso dura como máximo 0,5 s.

```bash
.venv-a2/bin/python a2_robot.py bench --policy-update 4000 \
  --iface "$IFACE" --seconds 0.5 --command forward \
  --bench-profile pruebas/a2-bench-profile.json \
  --csv "pruebas/u4000-banco-$(date +%Y%m%d-%H%M%S).csv"
```

La comprobación de U4000 se realizó en MuJoCo y DDS local. La puesta en marcha física del actor y la marcha con el GRU en el piso siguen pendientes.
